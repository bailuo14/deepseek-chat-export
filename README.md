# DeepSeek 聊天记录导出（浏览器扩展）

DeepSeek 开始清理长期闲置（约 7 天未使用）的会话。本扩展在
[chat.deepseek.com](https://chat.deepseek.com) 网页版内运行，用你自己的登录态
把**全部聊天会话**批量拉下来，导出为 **Markdown / JSON** 文件保存到本地。

> 🔒 隐私：所有请求都以你浏览器的同源身份直接发给 DeepSeek 官方接口，
> 文件在你本机内存里生成后由浏览器下载。**不经过、不上传任何第三方服务器**，
> 扩展本身不含任何后台/统计代码（`manifest.json` 里没有 permissions 字段，可自行查看）。

## 功能

- 📋 一键拉取**全部会话列表**（自动翻页，按最近活跃排序，标注当前会话）
- 🔎 按标题 / ID 搜索，勾选任意子集导出，或「导出全部 / 导出当前会话」
- 📄 导出格式：Markdown（适合阅读、喂给其他 AI）、JSON（适合程序处理）、或两者都要
- 🗂 文件方式：全部会话合并成**单个文件**（推荐，避免批量下载弹窗），或每个会话单独一个文件
- 💭 保留**思考过程（reasoning）**、模型名、消息时间
- 🧯 失败重试：网络抖动自动退避重试；个别会话失败不影响整体，完成后可单独「重试失败项」
- ⚠️ 风险提醒：加载列表后自动统计有多少会话已超过 7 天未活跃（属于清理风险对象）
- 🧲 「JSON 含原始数据」选项：把接口返回的每个字段原样附上（`_raw`），未来接口改版也不怕丢数据

## 安装（Chrome / Edge 通用，约 1 分钟）

1. 下载/保留本目录 `deepseek-export-extension` 文件夹（不要删除其中 3 个文件）。
2. 打开浏览器扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
3. 打开右上角（Edge 在左侧）的 **「开发者模式」** 开关。
4. 点击 **「加载已解压的扩展程序」**，选择 `deepseek-export-extension` 文件夹。
5. 打开（或刷新）`https://chat.deepseek.com`，确保已登录——右下角会出现
   蓝色的 **「📥 导出」** 悬浮按钮。

> 提示：用「加载已解压的扩展程序」安装时，这个文件夹不能删；想更稳妥可以把它
> 放到固定位置，或打包成 `.crx`/zip 备份。

## 使用

1. 点右下角 **「📥 导出」**（快捷键 `Alt + Shift + E`）打开面板。
2. 点 **「🔄 刷新列表」**，等待会话列表加载完成。
3. 选好格式和文件方式，点 **「导出全部会话」**（或勾选若干会话后「导出已选」）。
4. 文件会下载到浏览器默认的下载目录。

建议：
- 首次备份直接用默认值（Markdown + 合并单文件），一次拿到完整全量。
- 想长期留档，再加选一次 **JSON + 勾上「含原始数据」**，这是最全的机器可读备份。
- 若选「每个会话单独文件」且会话较多，浏览器会询问 *是否允许下载多个文件*，
  请点「允许」。

## 导出文件长什么样

**Markdown（合并模式）**：文件头有目录，每个会话一个一级标题，消息按时间排列：

```markdown
# 关于 Rust 生命周期的讨论

> 会话 ID：`0f0e...`
> 创建时间：2026-10-02 21:14 ｜ 最后更新：2026-11-08 09:32 ｜ 消息数：42

---

## 👤 用户 · 2026-10-02 21:14
……

## 🤖 DeepSeek · 2026-10-02 21:14 · `deepseek-chat`
<details><summary>💭 思考过程</summary>……</details>
……
```

**JSON（合并模式）**：

```jsonc
{
  "tool": "deepseek-export-extension",
  "version": "1.0.0",
  "exported_at": "2026-11-16T…",
  "session_count": 128,
  "sessions": [
    {
      "id": "…", "title": "…",
      "created_at": "…", "update_time": "…", "message_count": 42,
      "messages": [
        { "role": "user", "content": "…", "created_at": "…" },
        { "role": "assistant", "content": "…", "reasoning_content": "…", "model": "deepseek-chat", "created_at": "…" }
      ]
    }
  ]
}
```

## 工作原理与常见问题

- **原理**：扩展脚本只注入到 `chat.deepseek.com` 页面，用你浏览器的登录 Cookie；
  若接口要求令牌（2026-11 起需要），在面板「手动粘贴 accessToken」贴一次即可长期保存。
  调用 DeepSeek 网页版自身接口（`/api/v0/chat_session/fetch_page` 游标翻页列表、
  `/api/v0/chat/history_messages` 消息正文在 `fragments[]` 片段流中），在本地整理成文件。
- **v1.0.1（2026-11-16）**：适配 DeepSeek 接口改版——fetch_all 退役→fetch_page 游标翻页；
  响应改 biz_code/biz_data 信封；正文迁入 fragments 片段流；新增"结构证词"诊断
  （解析失败只报键名结构，绝不输出内容值）。41 项冒烟测试全绿。
- **「登录状态无效 / is_auth_err」**：网页端登录过期了，在页面上重新登录后再点导出。
- **「未检测到登录状态」**：同上，先在 `chat.deepseek.com` 登录。
- **列表为空**：点「刷新列表」；若一直为空，可能是 DeepSeek 接口改版，请把面板日志
  区的报错内容发给我更新工具。
- **速度慢**：把「并发」调大到 5；若频繁报错/限流，调回 1。
- **能恢复吗**：导出的 JSON（含 `_raw`）保留了接口返回的全部字段，Markdown 可直接
  阅读或作为上下文喂给 AI；但 DeepSeek 官方没有“导入会话”接口，导出的文件不能
  变回网页里的会话记录，请理解为**备份留档**而非搬家。
- **为什么建议常备**：与其指望手动“摸一下”每个会话来保活，不如定期全量导出——
  建议每周跑一次「Markdown + JSON 合并单文件」，几分钟搞定。
